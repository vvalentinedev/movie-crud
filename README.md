## Summary
MoviesDB is a Web Application to check data about your favorite movies. Built with Spring Boot and Angular.

## Instructions
In order to run this application locally you must:
1) Create a MySQL database with the tables defined in the table_creation.sql file available in the repository
2) Insert the data from bulk_insert_1.csv (also available in the repo) to the database
3) Configure your database credentials in the Spring Boot application (located in the Movies folder) 
4) Run the Spring Boot application
5) Run the Angular application (located in the moviesFront folder)
